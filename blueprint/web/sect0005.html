When \(\deg (f) \ne 0\), \(|\deg (f)| = [\pi _1(Y) : f_* \pi _1(X)] = k \ge 1\), and equality holds in Theorem 1.1, homothetic rescaling by \(c = h(\overline{X})/h(\widetilde{Y})\) and lifting to the degree-\(k\) cover \(p : \widehat{Y} \to Y\) give \(|\deg (\hat{f})| = 1\) and \(\mathcal{H}_c^N(X) = \mathcal{H}^N(\widehat{Y})\). The \(1\)-Lipschitz limit map \(\hat{F}_\infty : X \to \widehat{Y}\) then saturates the mass-Jacobian sandwich (\(\mathrm{Jac}_x \hat{F}_\infty = 1\) a.e.), is surjective, promotes to a global metric isometry \((X, c\, \mathsf{d}_X) \xrightarrow {\sim } \widehat{Y}\), and forces \(\mathcal{S}(X) = X \setminus \mathcal{R}_N(X) = \emptyset \).

Proof ▶

Combines finite_cover_entropy_degree_reduction, homothetic_normalization, the a.e. integral sandwich \(\mathcal{H}^N(\widehat{Y}) \le \int _X \mathrm{Jac}_x \hat{F}_\infty \le \mathcal{H}_c^N(X) = \mathcal{H}^N(\widehat{Y})\), surjectivity from \(\deg (\hat{F}_\infty ) \ne 0\), and Lipschitz-volume rigidity.
